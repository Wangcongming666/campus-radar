# 启程校招前端验收清单

## 学生端

- 首页能显示招聘季、搜索、近期截止、热门公司和三个求职工具入口。
- 首页关键词搜索能进入职位列表并保留关键词。
- 职位列表支持城市、岗位、学历、排序和清空条件。
- 职位详情能创建待确认投递记录，并打开虚构的官方投递地址。
- 公司库支持搜索；公司详情能显示公司信息和在招职位。
- 面试宝典能切换攻略与题库，题目的参考思路默认收起。
- 登录弹窗能校验邮箱和六位验证码；演示验证码 `246810` 可以登录。
- 个人中心能查看资料、收藏空状态、浏览记录和通知。
- 投递看板能切换看板与列表，修改非终态投递阶段并查看时间线。
- 简历中心能新建、删除和编辑简历。
- 简历编辑器支持基本信息、教育、实习、项目、技能和荣誉；条目可增删与上下移动。
- 简历可切换“经典专业”和“现代简洁”模板，主题色可调整，打印可导出 PDF。

## 运营后台

- 工作台能显示公司、职位、临期职位和文章数量。
- 公司管理能搜索、新增、编辑、启用和停用公司。
- 职位管理能搜索、选择和上下架职位，下架前有明确确认。
- 招聘批次能查看并切换启用状态。
- 职位导入能载入演示文件，区分有效行与错误行，并显示字段级错误。
- 面试内容能切换文章和题库列表。
- 用户管理能搜索、禁用和恢复账号。
- 运营账号、系统配置和操作日志页面可访问，并体现超级管理员权限。

## 响应式与可访问性

- 在 320px、768px、1024px 和 1440px 宽度下没有遮挡主要操作的布局问题。
- 学生端窄屏导航可展开；后台窄屏导航可以横向浏览。
- 使用键盘可以到达主要链接、按钮和表单控件，并能看到焦点样式。
- 表单字段有可读标签，错误信息不依赖颜色表达。
- 系统启用“减少动态效果”时，不播放非必要过渡动画。
