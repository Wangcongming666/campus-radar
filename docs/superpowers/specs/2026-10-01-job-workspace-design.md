# 求职工作台设计（增强子项目 1/4）

## 1. 文档目标

本文定义"求职工作台"子范围的产品与前端设计。它是四轮前端增强的第一轮，总体目标是把现有验收级原型升级为功能全面、体验人性化的产品。四个子项目的顺序为：

1. 求职工作台（本文）
2. 内容与工具扩充（面试宝典扩容、模拟面试、求职准备清单、薪资参考）
3. 简历编辑器进化
4. 运营后台增强

每个子项目独立经历设计、计划、实现与验收，互不阻塞。人性化设计原则（空状态引导、骨架屏、防误操作、键盘可达、尊重 `prefers-reduced-motion`）不单独立项，融入每个子项目。

## 2. 定位

现有投递看板是"用户主动查的记录工具"。本轮把它升级为**主动求职助手**：学生打开个人中心，第一屏就回答"今天该做什么"。工作台基于投递记录、收藏和职位截止数据，用规则生成建议行动，配上统计、日历和职位对比，覆盖求职主线从"记录"到"决策"的闭环。

不做的：浏览器系统通知（避免权限弹窗打断）、邮件/短信提醒、自动投递、第三方日历同步。

## 3. 信息架构

### 3.1 路由与导航

- `/me/applications` 改为 `/me/workspace`，旧路由重定向，避免书签失效。
- 学生端导航文案"投递看板"改为"求职工作台"。
- 页面内部为四个 Tab：**今日聚焦**（默认）、**看板**、**列表**、**日历**。Tab 状态写入 URL 查询参数（`?view=board`），支持刷新与分享保留视图。

### 3.2 今日聚焦（默认 Tab）

自上而下：

1. **临期预警条幅**：未来 7 天内截止且未到终态的投递 + 收藏未投递的职位，按剩余天数着色（≤3 天醒目警示色）。
2. **建议行动卡片流**：见第 4 节建议引擎。
3. **统计区**：投递漏斗（七阶段水平条形）、本周投递节奏（近 7 天小柱状）、关键数字（面试中 / Offer / 待跟进）。图表用现有 CSS 设计令牌手绘，不引入图表库。
4. **到期提醒区**：已到期与今天到期的自定义提醒列表，一键跳转对应投递。

### 3.3 看板 Tab

沿用七阶段列，卡片升级：

- 卡片右上角显示"停留 N 天"；超 7 天未变化的卡片显示提示角标。
- 临期投递卡片显示红色截止角标（"3 天后截止"）。
- 卡片操作菜单：归档、修改备注。
- 保留点击卡片打开详情抽屉。

### 3.4 列表 Tab

现有列表基础上增加：阶段筛选、归档状态筛选（进行中 / 已归档 / 全部）、按更新时间或截止时间排序、批量归档/恢复。归档记录在列表中淡化展示，可恢复。

### 3.5 日历 Tab

月历视图，当前月份网格：

- 每日格子展示：投递截止日（按紧急度着色的标记）、自定义提醒、招聘季起止日。
- 日期点击展开当日事件列表（含跳转）。
- 上/下月切换、回到今天。窄屏降级为周视图。

## 4. 建议行动引擎

纯前端规则引擎，输入为 `Application[]`、收藏职位、当前日期，输出 `Suggestion[]`。每条建议包含：类型、文案、可选操作（直达路由）与优先级。规则：

| 规则 | 触发条件 | 文案示例 | 操作 |
|------|----------|----------|------|
| 跟进 | 投递 7 天无事件且非终态 | "星海科技的后端开发已经 7 天没有动静了，发封跟进邮件试试？" | 查看时间线 |
| 确认投递 | `pending_confirmation` 停留超 3 天 | "这个职位你还没确认投递，是想再想想吗？" | 确认投递 / 放弃 |
| 临期收藏 | 收藏职位 3 天内截止且未投递 | "你收藏的『产品助理』后天就截止了" | 去看职位 |
| 面试准备 | 进入 interview 阶段 | "准备面试正当时，看看这家公司的面经？" | 直达面试宝典（按公司过滤） |
| Offer 决策 | 进入 offer 阶段 | "恭喜！记得在截止日前回复" | 记录答复（打开该投递的详情抽屉并聚焦备注输入框） |

- 规则为纯函数，表驱动单测。
- 建议按优先级排序，同屏最多展示 5 条，其余折叠为"还有 N 条建议"。
- 建议可"不再提醒"（单条dismiss，会话内记住，不落库）。

## 5. 职位对比

挂在学生端职位列表页：

- JobCard 增加"对比"勾选，最多选 3 个；底部浮出对比条显示已选职位，可移除。
- 对比条按钮打开对比抽屉：并排表格对比薪资、城市、学历要求、截止时间、公司（行业/规模/性质）、职位要求；**差异字段高亮**，相同字段弱化。
- 离开职位页或清空选择后对比状态释放，不持久化。

## 6. 数据层扩展

`CareerRepository.applications` 新增方法：

```ts
archive(id: string, value: boolean): Promise<void>
setNote(id: string, note: string): Promise<Application>
reminders: {
  add(applicationId: string, remindAt: string, title: string): Promise<Reminder>
  remove(id: string): Promise<void>
}
```

- Mock 仓储同步实现并持久化；`localStorage` 键从 `career-launch-mock-v1` 升级为 `v2`，读取旧数据时迁移（补默认字段），失败则回退种子数据。
- 打开工作台时，计算已到期/当日到期的提醒，写入通知列表（`deadline` 类型 Notification），并标记提醒为 `sent`，避免重复。
- 前端展示层新增 `Suggestion` 视图模型（不入 shared 领域模型，属页面逻辑）。

## 7. 人性化细节

- 空状态给出下一步引导：零投递 →"从浏览在招职位开始 →"直达职位页；零收藏 → 引导收藏流程说明。
- 放弃投递、删除提醒等不可逆操作需二次确认，确认文案说明后果；"确认投递"类操作即时可撤销提示。
- 列表与看板加载用骨架屏，替代当前 220ms 延迟下的空白。
- 时间显示人性化："3 天后截止""今天""已过期 2 天"；hover/`title` 提供精确日期。
- 键盘可达：Tab 切换、卡片菜单、日历格子均可键盘操作并显示焦点。
- `prefers-reduced-motion` 时禁用非必要过渡。
- 对比抽屉窄屏降级为上下堆叠。

## 8. 测试

- 建议引擎：规则表驱动单测（触发/不触发/优先级/dismiss）。
- 仓储新增方法：契约测试（archive/setNote/reminders 持久化、迁移逻辑）。
- 临期计算、人性化时间格式：纯函数单测。
- 现有测试全部保持通过；不引入新依赖。

## 9. 验收要点

- 打开工作台默认看到"今日聚焦"，能回答"今天该做什么"。
- 四个 Tab 均可用，URL 查询参数保留视图状态。
- 建议引擎对演示数据产出可验证的建议卡片，操作按钮可达目标页。
- 提醒真实落地：设置 → 持久化 → 到期出现在通知列表。
- 职位对比可选 2-3 个职位并排查看，差异高亮。
- 归档/恢复、备注编辑、批量操作可用。
- 320px/768px/1024px/1440px 无遮挡；键盘可完成主流程。
