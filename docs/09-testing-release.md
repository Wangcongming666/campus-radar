# 测试、验收与发布

本文说明检查入口与业务场景。启动与日常开发见 [开发指南](08-development.md)，已执行的检查、时间与限制见 [最新交接](HANDOFF.md)。

## 1. 测试分层

| 层 | 工具与范围 | 必须证明 |
| --- | --- | --- |
| 规则 | JUnit5；前端纯展示逻辑Vitest | 金额/日期/排序/规则版本/空值/时区边界 |
| HTTP与权限 | MockMvc + 真实Service | Cookie/CSRF、字段校验、归属、角色、409及状态码 |
| 数据集成 | Compose MySQL8.4独立验收库 | 外键、唯一约束、生成列默认简历、全文索引、分页和并发 |
| 基础设施 | Compose Redis/RabbitMQ + 本机Mailpit | 会话撤销、限流原子性、Outbox重发、Inbox去重和重试 |
| 前端组件 | Vitest规则及真实浏览器页面 | 失败保留草稿、409、键盘、未知值/空态；不当作真实后端验证 |
| 全链路 | Playwright→Java→MySQL/Redis/RabbitMQ | 真实双账号、文件字节、任务成功/失败恢复与页面联动 |
| 视觉 | Playwright固定视口/时钟/字体与截图审查 | 39页结构、主题、溢出、关键断点；有旧版基准才声称视觉一致 |

开发者可按改动单独运行单元测试；真实集成检查需要 Docker 及相关依赖。跳过的用例应单列，不能写“全通过”。测试数据独立库与目录，禁止指向用户正式库或旧项目数据库。

## 2. 必测业务场景

1. 游客读取岗位/面经/宝典；点击收藏才登录；安全returnTo、伪造外部回跳拒绝。
2. 注册受理→直接登录（不生成验证令牌或邮件）；匿名/登录CSRF错误；重置单次令牌/过期/重放；改密码旧会话失效。
3. 中文两字搜索、多维筛选、空q/单字q、稳定排序与分页边界；未知日期/薪资；未审核内容无法通过详情或搜索泄漏。
4. 同岗位并发加入只产生一条投递；两标签同时移动只有一个成功；错邻居/跨账号邻居拒绝；重排后刷新与撤销一致；超10分钟和非最新撤销409。
5. 本人笔记自动保存失败、迟到响应、账号切换、409保留草稿；章节版本变化不抹掉笔记。
6. 两账号文件ID互猜404；MIME/头不符、超限、路径文件名、引用中删除拒绝；PDF预览/提取/空扫描版、上传和下载SHA-256一致；默认简历并发唯一。
7. 面试轮次/日程双方修改同步；相邻时段不冲突，重叠提示；时区跨天、取消轮次、ICS转义/换行、复盘录音归属。
8. 题库练习暂停/恢复/超时/重复提交、答案不可越权；提交后写入拒绝；无题目不生成伪结果。
9. 统计0分母null，归档历史、撤销、跨年/时区；Offer缺月数/缺维度/0权重；薪资n<5抑制。
10. Rabbit发布前宕机、confirm后未记账宕机、消费者处理后ack前宕机；重复事件不重复业务；租约过期旧token不可写回；失败后定时重试可恢复。
11. 订阅停用、岗位版本更新/同版本重扫、重复到期提醒、SMTP故障；站内通知只一次，外部邮件如重复有可追溯Message-ID。
12. 房间并发抢最后名额、过期邀请、非房主创建任务、退出后读取拒绝；内推双方状态机和申请隐私。
13. 内容提交/编辑/审核/下架、评论越主题父节点、举报闭环；REVIEWER不能读私人附件或授予角色。
14. 导出一致性快照、恢复版本冲突/坏签名/跨账号/ZIP bomb/文件缺失、进程中断、失败不部分替换；注销立即撤销会话，擦除失败可运维重试。

## 3. 检查入口

在项目根目录按改动执行：

```sh
./backend/mvnw -f backend/pom.xml test
npm --prefix frontend run generate:api
npm --prefix frontend run typecheck
npm --prefix frontend test
npm --prefix frontend run build
```

可选的 `./scripts/verify-live.sh` 在独立测试库上运行真实全链路验收。它不是日常启动步骤，也不应指向已有业务库。Playwright 的 `*-real.spec.ts` 需要真实后端和依赖，测试配置与隔离数据须配套使用。

API 合同检查核对 `$ref`、operationId、请求/响应和页面映射；生成类型不能代替实际 HTTP 检查。[完整 SQL](contracts/schema.sql) 是新空库初始化入口，真实数据库结构检查只能针对明确的独立测试库进行。

## 4. 证据与范围

记录检查日期、命令、环境、通过/失败/跳过数量和剩余限制。只有实际执行成功的检查才能写为通过，单元测试不能替代真实依赖或浏览器验证。

本机邮件使用Mailpit。日常启动只需保持本机依赖运行；不要删除数据卷或重复执行建表SQL。
